# پنجره‌های آلپاین — وب‌سایت تک‌صفحه‌ای

وب‌سایت فارسی (راست‌چین) برای برند «پنجره‌های آلپاین»؛ نورگیرهای سقفی هوشمند و پنجره‌های سه‌جداره.
این پروژه از آرشیو `clone-website-with-placeholders (7).zip` استخراج شده و محتوای جای‌نگهدار آن با محتوای کامل و متناسب با تصاویر واقعی پروژه (`public/images`) جایگزین شده است.

## امکانات صفحه

- هیروی تمام‌صفحه با انیمیت اسکرول GSAP (پین + زوم + تكشف عنوان) و تصویر `hero.jpg`
- بخش نقل‌قول با آشکارشدن کاراکتری هنگام اسکرول
- کارت‌های محصولات با نمودارهای SVG اختصاصی (نور فصل‌ها، کاهش اتلاف انرژی، عایق صوتی، پایداری دما)
- دیاگرام «آناتومی پنجره سه‌جداره» با لایه‌های شیشه، گاز آرگون و پوشش Low-E
- کاربردها، پروژه‌ها (با تصاویر `project1-3.jpg`)، فرایند نصب چهارگام، آمار، بند «نصب، نیمی از محصول است» (با `install.jpg`)، نظرات، پرسش‌های متداول، CTA، فرم تماس و فوتر
- ناوبری چسبان با هایلایت بخش فعال، منوی موبایل و اسکرول نرم

## اجرا

```bash
npm install
npm run dev      # پیش‌نمایش توسعه
npm run build    # خروجی نهایی در dist
```

## انتشار روی GitHub Pages

با ادغام روی شاخه `main`، گردش‌کار «Deploy to GitHub Pages» (فایل `.github/workflows/pages.yml`) به‌صورت خودکار build گرفته و روی گیتهاب پیج منتشر می‌کند:
https://rahmaniho.github.io/Demo/
